## 🪙 Sobre

**Aurum** é uma aplicação de gestão financeira desenvolvida com foco em **performance local** e **tipagem estática**. O projeto visa entregar uma experiência de usuário fluida para controle de ativos, utilizando a leveza do SQLite combinada com a segurança do TypeScript.

A escolha do nome (latim para "ouro") reflete a filosofia do código: valioso, durável e brilhante.

## 🛠 Tech Stack

Este projeto foi construído utilizando as melhores práticas do ecossistema JavaScript/TypeScript:

* **Linguagem:** [TypeScript](https://www.typescriptlang.org/) (Superset tipado para JS)
* **Banco de Dados:** [SQLite](https://www.sqlite.org/index.html) (Leve, serverless e rápido)
* **Framework:** [Next.js / React / NestJS] *(Edite aqui)*
* **Estilização:** [Tailwind CSS / Styled Components / Sass] *(Edite aqui)*
* **ORM:** [Prisma / TypeORM / Drizzle] *(Recomendado para TS + SQLite)*
